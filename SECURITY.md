# Security Policy

## Supported Versions

We typically only support the latest release of the Terraform Provider for LavinMQ for maintenance updates,
but depending on the nature of the security issue we may issue hotfixes for earlier versions.

## Reporting a Vulnerability

If you discover any issue regarding security, please disclose the information responsibly by
sending an email to security@84codes.com and not by creating a GitHub issue.
We'll get back to you ASAP and work with you to confirm and plan a fix for the issue.

Please note that we do not currently offer a bug bounty program for this provider.
